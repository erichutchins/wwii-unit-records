# USS Yorktown (CV-10): April 1945 war diary, 6 April only (so far)

`positions.csv` is transcribed from the April 1945 war diary ([NARA 140001274](https://catalog.archives.gov/id/140001274), 66 pages): the 0800, 1200 and 2000 positions of 6 April 1945 (`p11`, read on the scan). Zone stated: the page's date line types "Zone description - Minus 9". Task Group 58.4. Other days are not transcribed (lead L49).
