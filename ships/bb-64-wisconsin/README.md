# USS Wisconsin (BB-64): April 1945 war diary, 6 April only (so far)

`positions.csv` is transcribed from the April 1945 war diary ([NARA 139992751](https://catalog.archives.gov/id/139992751), 16 pages): the 0800, 1200 and 2000 positions of 6 April 1945 (`p03`, read on the scan). Zone assumed: No zone is typed on this page (the diary is Wisconsin's; Missouri's p03 types Zone Time -9 for the same group). Task Group 58.4. Other days are not transcribed (lead L49).
